## FinQA 全量端到端评测（2026-09-12）

评测器复现官方顺序程序 DSL、数值执行语义和符号等价 Program Accuracy；先用 Dev 全量

Accuracy 提升 **1.13 个百分点**；不能把从首行到冻结配置的全部提升归因于校验环。Public
Test 引用 Precision/Recall 为 88.40%/82.89%，格式有效率 99.56%，程序可执行率 92.33%；两轮

## 开发中发现并修正的问题

早期记录保留用于复盘，未删除失败运行：#2、#3 暴露了引用格式问题；#4 暴露了计算失败后模型仍自行生成结论的问题。#4 已添加人工修正记录，不计入完整流程验收。

当前实现使用任务内短引用编号；无效引用返回明确校验反馈，在原有步数预算内修正。已失败的计算必须再次成功，才能完成任务。始终保留证据权限、引用存在性和终态约束，不以历史答案、空文本或模型自称完成代替成功。

## 与简历技术要点的对应

| 技术要点 | 主要代码 | 可说明的边界 |
| --- | --- | --- |
| Spring MVC 分层、参数和异常处理 | ApiController / AuthController / DocumentService / TaskService / Errors | 仅实现当前业务所需接口，没有微服务治理 |
| MySQL / MyBatis、幂等与事务 | db/migration / DataMapper.xml / TaskService | 真实数据库；审阅短事务不包裹模型调用 |
| ReAct / Multi-Agent | AgentEngine | 自主工具选择和可选子 Agent；不是固定多角色流水线 |
| 上下文压缩和完成校验 | WorkingMemory / AgentEngine | 字符预算、完整调用配对、引用及计算校验；不等同事实准确性证明 |
| 并发和异步执行 | Pools / Gateway / TaskService | 分离有界池、CompletableFuture、取消与超时；不保证云端任务停止计费 |
| SSE 与历史追溯 | ApiController / task_events | 持久化事件重放，不自动重跑模型任务 |
| 金融文档 RAG | rag/app.py | 中文 BM25 + 向量 RRF；支持 PNG/JPG 文字 OCR，不支持扫描 PDF OCR 或外部链接自动抓取 |

## 性能观察（非正式基准）
