# Sample documents

The repository contains one synthetic text document for a no-license-risk smoke test:
`synthetic_financial_report.txt`.

The annual reports and regulatory documents used in the local acceptance record are not
redistributed. Put only documents you are authorized to process in this directory, or upload them
from the application. Local PDF and HTML files under `samples/` are ignored by Git.

Sample content and model output are for technical evaluation only. They are not investment, legal,
or compliance advice.
